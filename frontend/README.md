# ML Risk Detection — Frontend Foundation

This is **Phase 2** of the frontend roadmap. Phase 1 foundation is included.

Implemented:
- React + TypeScript + Vite
- Tailwind CSS
- shadcn-style UI primitives
- Lucide React
- React Router
- React Hook Form + Zod dependencies ready
- Axios service boundary
- Responsive base layout
- Professional financial/AI visual foundation
- Application header and branding
- Two model cards with clear navigation
- Loan and Fraud entry points
- Placeholder routes for Loan and Fraud
- Mock service location prepared
- Phase 2 home-page polish and responsive states

Not implemented yet:
- Loan workflow
- Fraud workflow
- Form schemas/metadata
- Wizard implementation
- Real/mock prediction UI
- FastAPI integration

Backend details remain isolated because the backend developer will provide the API contract later.

## Run

Requires Node.js 24 LTS and npm.

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Next phase

Phase 3 is the shared wizard foundation: progress indicator, step container, navigation, persistent form state, validation, and responsive behavior. Initially it should use placeholder steps.
